This folder contains EddyPro settings (.eddypro) and metadata (.metadata) files that were used to calculate fluxes for the CH-CHA flux product.

Files are named following the convention:
CH-CHA_<year(s)>_<period>_[<instrument(s)>]_<system configuration>

The EddyPro settings files are part of the documentation and can be used to reproduce the flux calculations.

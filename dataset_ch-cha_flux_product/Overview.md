# Overview

The dataset was created using homogenized eddy covariance (EC) flux processing sites across all years. It combines ecosystem fluxes with meteo data and detailed management information. 

EC measurements at the research site [CH-CHA (Chamau)]((https://www.swissfluxnet.ethz.ch/index.php/sites/site-info-ch-cha/)) in Switzerland started in 2005, and at the time of writing measurements are ongoing. 

This documentation consists of various sections that give details about the respective variables and processing steps. In addition, we provide all Jupyter notebooks that were used to create the dataset.
